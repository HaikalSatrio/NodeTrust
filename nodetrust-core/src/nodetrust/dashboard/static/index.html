How decisions are made

  • NORMAL: pass (not a certification of safety).
  • WATCH: warn; e-mail only if the project enables it.
  • INVESTIGATE or unverified CRITICAL: warn, e-mail, triage. Scores alone never block.
  • Verified CRITICAL, exact version, small radius: monitor warns; enforce gates only if pre-authorised.
  • Verified CRITICAL with large or unknown radius: escalate; enforce holds for approval only if pre-authorised.
  • Stale or incomplete data: monitor warns UNKNOWN; enforce reports "assessment unavailable".
