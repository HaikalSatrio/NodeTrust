# NT-004: package to Neo4j to reverse blast-radius spike

Owner: Haikal. Reviewer: Brian. Review candidate, 28 September 2026.
Branch: `haikal/nt-004-005`, based on NT-003 commit `c95ca75`.

Acceptance: load one package and its dependencies into Neo4j; reverse traversal
from an existing dependency returns dependents and hops matching a manual fixture.

The implementation uses normalized npm-shaped synthetic metadata from
`fixtures/nt004/graph.json`. The NT-005 resolver builds the version graph, then
`graph/neo4j_spike.py` loads it into actual Neo4j, using parameterized Cypher.
The existing application still uses SQLite; this experiment is not a store migration.

## Manual expected graph

Every node has ecosystem npm and an exact version. Abbreviations below mean
`ntdemo-app`, `ntdemo-left`, `ntdemo-right`, and scoped `@ntdemo/leaf`.

| Dependent | Dependency | Declaration |
|---|---|---|
| app@1.0.0 | left@1.0.0 | prod, ^1.0.0 |
| app@1.0.0 | right@1.0.0 | prod, 1.0.0 |
| left@1.0.0 | leaf@1.0.0 | prod, npm:@ntdemo/leaf@^1.0.0 |
| left@1.0.0 | leaf@1.1.0 | same alias declaration, another possible version |
| right@1.0.0 | leaf@1.0.0 | peer, 1.0.0 |
| leaf@1.0.0 | left@1.0.0 | prod, 1.0.0; cycle |

The optional `ntdemo-missing@^1` stays unresolved and creates no Neo4j node/edge.
Starting at leaf@1.0.0: left and right are hop 1; app is hop 2. The cycle must
not include the seed as its own dependent. leaf@1.1.0 is not a reverse dependent.
Expected totals: 5 nodes, 6 edges, 3 dependents, 1 unresolved declaration.

## Reproduce

Install core with its development dependencies and set `NEO4J_PASSWORD` in
the environment or the core `.env`. For the existing Compose profile:

```bash
docker compose --profile neo4j up -d neo4j
python scripts/spike_nt004.py
```

An alternate loopback port is supported:

```bash
python scripts/spike_nt004.py --url http://127.0.0.1:17474
```

The script loads the graph twice, checks counts and dependent hop rows against
the fixture, and removes only its UUID-scoped `NT004PackageVersion` nodes in
`finally`. A failing query, missing seed, wrong count, wrong hop, or failed
cleanup causes a nonzero exit. It refuses non-loopback origins and redirects.
Credentials are not included in reports. GDS/APOC are not required.
